# Historical projects and retained upstream references

This page keeps older repositories discoverable without presenting them as the current CRAYS service stack.

## No longer used in the current stack

| Repository | Classification | Current navigation |
| --- | --- | --- |
| [Twenty](https://github.com/CraysCircle/twenty) | Historical CRM fork; the owner has confirmed it is no longer used. | For current business/finance integrations, start with the [platform service hub](https://github.com/CraysCircle/crays-platform/blob/main/docs/services/README.md). This is not a claim that every former CRM feature has been replaced. |
| [OpenProject](https://github.com/CraysCircle/openproject) | Historical project-management fork; the owner has confirmed it is no longer used. | [Plane within Work](https://github.com/CraysCircle/crays-platform/blob/main/docs/services/plane.md) is the canonical current project-integration entry. |

The original repositories, history and license terms remain intact. This classification does not delete or rewrite their source and does not claim that a repository has been formally archived in GitHub.

## Upstream references are not complete CRAYS products

[Calendar](https://github.com/CraysCircle/calendar) is a fork of Nextcloud Calendar, not the complete Nextcloud server. [CRM](https://github.com/CraysCircle/crm) preserves a Frappe CRM fork; the current finance integration is documented separately under [Frappe / ERPNext](https://github.com/CraysCircle/crays-platform/blob/main/docs/services/frappe.md). An installed app or retained fork alone does not establish its active CRAYS provider role.

[Primal](https://github.com/CraysCircle/primal-web-app) is a retained upstream reference; the CRAYS-derived Nostr web source remains separately identified in [crays-web-codex](https://github.com/CraysCircle/crays-web-codex).

## Find a particular older version

Use [the repository guide](repositories.md), [source/version verification records](verification-records.md) and the selected project's own history. Names such as a build number or migration source composition identify source states, rather than new user-facing products.

The main [CRAYS overview](https://github.com/CraysCircle) and [platform](https://github.com/CraysCircle/crays-platform) are the starting points for current product and contribution navigation.
