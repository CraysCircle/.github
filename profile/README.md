## Source, versions and licenses

The AWS migration and source reconciliation are in progress. Public access is being completed after source and history checks. The presence of a repository does not prove that its default branch is the exact deployed version.

For an AWS version, follow its source commit, file hashes, build/image identity and release record. Original license, copyright and NOTICE terms apply per project and component; there is no blanket license for this organization. Missing evidence remains explicit in [the current source and license status](https://github.com/CraysCircle/.github/blob/main/docs/source-and-license-status.md).

Secrets, private keys, customer data and database exports do not belong in the public source repositories. Complete technical source and reproducible instructions are documented separately from those runtime records.

## Working with these projects

Read the selected project's README and contribution instructions before making changes. For upstream forks, retain the upstream history and original license notices. See [how source changes reach an approved release](https://github.com/CraysCircle/.github/blob/main/docs/source-and-license-status.md#release-process).

See the [repository structure and update rules](https://github.com/CraysCircle/.github/blob/main/docs/repository-structure.md) for where current sources, shared components, operations and historical versions belong.
